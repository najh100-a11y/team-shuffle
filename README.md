# TeamShuffle

출석한 사람만 골라 성비와 연령 비율이 고르게 팀을 나누는 무료 프로그램입니다. 교회 소그룹, 동아리, 수련회, 수업 조 편성처럼 매주 팀을 새로 짜야 하는 모임을 위해 만들었습니다. Windows와 Mac에서 설치해서 쓰며, 모든 데이터는 사용하는 컴퓨터 안에만 저장됩니다.

## 할 수 있는 일

- 명단 관리: 이름, 성별, 구분(예: 장년/청년)을 저장합니다. 여러 명을 한꺼번에 붙여 넣을 수 있습니다.
- 출석 체크: 이름을 눌러 출석과 결석을 바꿉니다. 출석한 사람만 팀에 들어갑니다.
- 균형 있는 팀 나누기: 아래 순서대로 우선해서 맞춥니다.
  1. 꼭 다른 팀이어야 하는 사람은 다른 팀으로
  2. 팀마다 남녀 수를 고르게
  3. 팀마다 인원을 고르게
  4. 팀마다 두 구분(예: 장년/청년)을 고르게
  5. 성별과 구분의 네 조합을 고르게
  6. 전에 같은 팀이었던 사람끼리는 되도록 다른 팀으로

  앞 순위를 희생해서 뒤 순위를 맞추는 일은 없습니다. 예를 들어 사람을 섞으려고 남녀 균형을 깨지 않습니다.
- 함께 / 따로 규칙: 꼭 같은 팀이어야 하는 사람과 꼭 다른 팀이어야 하는 사람을 지정합니다.
- 손으로 고치기: 나눈 뒤에 이름을 끌어 다른 팀으로 옮기거나, 두 사람을 눌러 서로 바꿀 수 있습니다. 균형이 깨지면 화면에 바로 표시됩니다.
- 확정과 이력: 마음에 드는 편성을 확정하면 날짜와 함께 저장되고, 다음 추첨부터 반영됩니다.
- 만남 현황: 누가 누구와 몇 번 같은 팀이었는지, 아직 한 번도 같은 팀이 아니었던 사람은 누구인지 보여 줍니다.
- 결과 복사, 인쇄, 백업 파일 저장과 불러오기, 명단 CSV 저장

## 내려받기와 설치

[Releases](../../releases) 페이지에서 내 컴퓨터에 맞는 파일을 받습니다.

| 컴퓨터 | 파일 |
| --- | --- |
| Windows 10/11 | `TeamShuffle-Setup-버전.exe` |
| Mac (M1, M2, M3, M4 등 Apple 칩) | `TeamShuffle-버전-mac-arm64.dmg` |
| Mac (인텔 칩) | `TeamShuffle-버전-mac-x64.dmg` |

Mac의 칩 종류는 화면 왼쪽 위 Apple 메뉴의 "이 Mac에 관하여"에서 확인할 수 있습니다.

### Windows

설치 파일을 실행하면 바로 설치되고 바탕화면과 시작 메뉴에 TeamShuffle 바로가기가 생깁니다. 관리자 권한은 필요 없습니다.

이 프로그램은 유료 코드 서명 인증서 없이 배포되기 때문에, 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다. "추가 정보"를 누른 뒤 "실행"을 누르면 됩니다.

### Mac

dmg 파일을 열고 TeamShuffle을 응용 프로그램 폴더로 끌어다 놓습니다.

Apple 개발자 인증을 받지 않은 앱이라 처음 열 때 "확인할 수 없다"는 경고가 뜹니다. 그때는 경고 창을 닫고 시스템 설정 > 개인정보 보호 및 보안으로 가서, 아래쪽의 TeamShuffle 안내 옆 "그래도 열기"(macOS 버전에 따라 "확인 없이 열기")를 누릅니다. 한 번 열고 나면 다음부터는 경고가 뜨지 않습니다.

"손상되었기 때문에 열 수 없습니다"라는 메시지가 뜨면 터미널에서 다음을 한 번 실행한 뒤 다시 엽니다.

```
xattr -dr com.apple.quarantine /Applications/TeamShuffle.app
```

## 사용 순서

1. 명단 탭에서 사람을 추가합니다. 여러 명을 붙여 넣을 때는 한 줄에 한 사람씩 `이름, 성별, 구분` 순서로 적습니다. 예: `홍길동, 남, 장년`
2. 팀 나누기 탭에서 출석을 확인하고 팀 수를 정한 뒤 "팀 나누기"를 누릅니다.
3. 필요하면 사람을 옮기거나 바꾼 뒤 "이 편성으로 확정"을 누릅니다.

구분의 이름(장년/청년)과 위쪽 제목은 설정 탭에서 바꿀 수 있습니다.

## 데이터는 어디에 저장되나요

인터넷으로 보내지 않고 이 컴퓨터에만 저장합니다.

- Windows: `%APPDATA%\TeamShuffle\teamshuffle-data.json`
- Mac: `~/Library/Application Support/TeamShuffle/teamshuffle-data.json`

저장할 때마다 바로 전 상태를 같은 폴더의 `.bak` 파일로 남겨 둡니다. 다른 컴퓨터로 옮기거나 미리 보관해 두려면 설정 탭의 "백업 파일 저장"을 쓰세요.

## 개발자용

Node.js 22 이상이 필요합니다.

```
npm install
npm test        # 팀 나누기 알고리즘 검사
npm start       # 개발 모드로 실행
npm run dist:win   # Windows 설치 파일 (Windows에서)
npm run dist:mac   # Mac 설치 파일 (Mac에서)
```

### 새 버전 배포

1. `package.json`의 `version`을 올립니다. (예: 1.0.0 → 1.0.1)
2. GitHub 저장소의 Actions 탭에서 "Build installers"를 고르고 "Run workflow"를 누릅니다. `v1.0.1` 같은 태그를 push해도 됩니다.
3. 빌드가 끝나면 Releases에 Windows와 Mac 설치 파일이 올라갑니다.

### 구조

- `app/balancer.js` 팀 나누기 알고리즘 (브라우저와 Node 양쪽에서 동작)
- `app/app.js`, `app/index.html`, `app/styles.css` 화면
- `main.js`, `preload.js` Electron 데스크톱 앱 껍데기와 파일 저장
- `test/balancer.test.js` 알고리즘 검사
- `.github/workflows/build.yml` 설치 파일 자동 빌드
